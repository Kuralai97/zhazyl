# Postmortem: .gitignore және .env.example репозиторийге түспей қалды

Кінәсіз талдау: себептер жүйенің қасиеті ретінде жазылады, адамның аты-жөні себеп ретінде жазылмайды.

## Қысқаша
9-ЗЖ-ның 1-спринтінде T2 «Жоба қаңқасы» тапсырмасы «Дайын» болып белгіленді, бірақ репозиторийде .gitignore пен .env.example болған жоқ. Осы уақыт ішінде репозиторийге дерекқор файлы не құпиялары бар .env файлы кездейсоқ түсіп кетуден қорғау болмады.

| __:__ | .gitignore «Create new file» арқылы жасалды |

## Әсері
- Клиенттерге әсері жоқ: жүйе әлі жұмыс ортасына шықпаған.
- Репозиторий __ минут .gitignore-сыз болды. Осы аралықта __ коммит түсті.
- Құпия ағып кетпеді: gitleaks «no leaks found».
- 1 тапсырма (T2) «Дайын» болғаннан кейін қайта ашылды, DoD бұзылды.

## Факторлар
- Веб арқылы жүктеу нүктемен басталатын файлдарды ескертусіз өткізіп жібереді.
- DoD-тегі тексеру «файл ашыла ма» дегенмен шектелді, жүктелген файлдардың тізімі тапсырма папкасымен салыстырылмады.
- Міндетті файлдардың бар-жоғын автоматты тексеретін қадам болмады (ол кезде CI жоқ еді).
- Жалғыз анықтау құралы — скриншотты қараған сыртқы адам.

## Не жұмыс істеді
- Құпиялар басынан кодта емес, орта айнымалыларында: .env.example тек үлгі, нақты мәндер жоқ.
- gitleaks DoD-те болды, ол құпия жоқ екенін растады.
- Git тарихы хронологияны минутпен қалпына келтіруге мүмкіндік берді.
- Ретроспективаның өзгерісі (тізіммен салыстыратын чек-лист) 2-спринтте «Дайын»-нан кейінгі түзетулерді 1-ден 0-ге түсірді.
- 10-ЗЖ-да main бұтағы қорғалды: енді өзгеріс тек CI жасыл болғанда түседі.
