# UAT сценарийлері

Сценарийлерді тапсырыс беруші рөліндегі адам орындайды. Әзірлеуші үндемейді, тек жазып отырады. Әр сценарийдің өту шарты бар: оған «иә» не «жоқ» деп қана жауап беріледі.

Алдын ала: стенд іске қосылған, тестілік деректер жасалған (seed 42). Иесінің аккаунты: `iesi`.

## Клиент ретінде
| № | Не істейді | Нені көруі керек (өту шарты) |
|---|---|---|
| UAT-01 | Жазылу сілтемесін ашады | Қызметтер тізімі шығады; әр қызметтің атауы, ұзақтығы мен бағасы көрінеді |
| UAT-02 | Қызметті таңдайды, ертеңгі күнді басады, бос уақытты таңдайды, атын, +7-ден басталатын телефонын жазады, келісім белгісін қояды, «Жазылу» басады | «Сіз жазылдыңыз» деген бет шығады, онда қызмет, күн мен уақыт жазылған |
| UAT-03 | UAT-02-дегі күн мен қызметті қайта ашады | Өзі жазылған уақыт тізімде енді жоқ |
| UAT-04 (теріс) | Атын жазбай, қалғанын толтырып, «Жазылу» басады | Жазылу жасалмайды; «Атыңызды жазыңыз» деген хабар шығады |
| UAT-05 (теріс) | Телефонды «8701» деп жазып жібереді | Жазылу жасалмайды; телефонның дұрыс түрі көрсетіледі; жазған аты өшпейді |
| UAT-06 (теріс) | Келісім белгісін қоймай жібереді | Жазылу жасалмайды; «Жазылу үшін келісім қажет» деген хабар шығады |
| UAT-07 (теріс) | Жексенбі күнін таңдайды | «Бұл күні бос уақыт жоқ» деп шығады, жазылу формасы көрсетілмейді |
| UAT-08 (теріс) | Басқа браузерде (не жасырын терезеде) «Сіз жазылдыңыз» бетінің сілтемесін ашады | Басқа адамның жазылуы көрінбейді, «табылмады» шығады |

## Иесі ретінде
| № | Не істейді | Нені көруі керек (өту шарты) |
|---|---|---|
| UAT-09 (теріс) | Кірмей тұрып, әкімші панеліндегі жазылулар тізімінің сілтемесін ашады | Жазылулар көрінбейді, кіру беті шығады |
| UAT-10 | Кіріп, «Жазылулар» бөлімін ашады, «Бүгін» не келесі күн бойынша сүзеді, UAT-02-дегі клиентті телефоны бойынша іздейді | Клиенттің жазылуы табылады, қайдан келді — «Онлайн» |
| UAT-11 | Сол жазылуды белгілеп, «Өтті» деп белгілейді | Статус «Өтті» болып өзгереді |
| UAT-12 (теріс) | Жаңа қызмет қосады, ұзақтығын 3 минут деп жазады | Қызмет сақталмайды, қате хабары шығады |
