# Жүйені компьютерде іске қосу

1. Python 3.11 немесе одан жаңасын орнатыңыз.
2. Репозиторийді жүктеп, түбірінде командалық жолды ашыңыз.
3. Тәуелділіктерді орнатыңыз:
   ```
   pip install -r requirements.txt
   ```
4. Дерекқорды дайындаңыз және әкімші жасаңыз:
   ```
   cd src
   python manage.py migrate
   python manage.py createsuperuser
   ```
5. Іске қосыңыз:
   ```
   python manage.py runserver
   ```
6. Браузерде http://127.0.0.1:8000/admin/ ашып, әкімшінің логинімен кіріңіз. «Қызметтер» және «Жұмыс кестесі» бөлімдері сол жерде.

Тесттер: `python manage.py test`
