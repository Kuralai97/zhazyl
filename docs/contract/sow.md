# SoW — «Жазыл» MVP

| Бөлім | Мазмұны |
|---|---|
| Тараптар | Тапсырыс беруші — Әлібек Сапаров («Ұста» барбершопы). Орындаушы — Мырзатаева Құралай |
| Пәні | «Жазыл» MVP-ін әзірлеу, ҚР-дағы серверге орнату және тапсыру |
| Нәтижелер | 1) Веб-қосымша: қызметтер мен кесте, онлайн жазылу, растау, Telegram еске салғыш, күнтізбе, қолмен қосу, «Өтті / Келмей қалды». 2) ҚР-дағы VPS-ке орнатылған жүйе. 3) Нұсқаулық және runbook. 4) Бір оқыту сабағы. 5) Бастапқы код |
| Кіреді | 6-ЗЖ-да келісілген 17 MVP элементі |
| Кірмейді | Онлайн төлем, мобильді қосымша, бірнеше шебер/филиал, WhatsApp еске салғыш, ZHL-25, Kaspi/1С интеграциясы |
| Қабылдау | 14-аптада UAT, 8 сценарий, қабылдау хаттамасы |
| Қарау мерзімі | 5 жұмыс күні; ескерту болмаса — қабылданды |
| Өзгерістер | Тек айырбаспен: жаңа элемент кірсе, көлемі тең бір элемент шығады; шешімді иесі қабылдайды, шешімдер журналына жазылады |
| Тапсырыс беруші міндеттері | VPS ақысы 10-аптаға дейін; клиенттер базасы мен келісім мәтіні 12-аптаға дейін; аптасына 30 мин; UAT-қа 2 сағ |
| Нәтижеге құқық | Кодқа айрықша құқық тапсырыс берушіде; ашық компоненттер өз лицензиясымен |
| Шектеулер, жорамалдар | Семестрде ақшалай шығын 0 ₸; ДД ҚР-да; орындаушы аптасына 7 сағ; тапсырыс беруші кешіктірсе, мерзім жылжиды |

## Міндеттеме болып саналмайтыны
- Тапсырғаннан кейінгі қолдау және пысықтау — бөлек келісіммен.
- Ақаудың мүлде болмайтынына кепілдік.
- «Кірмейді» тізіміндегі және кейін сұралған функциялар.
- Telegram, хостинг және интернет-провайдердің жұмысы.
