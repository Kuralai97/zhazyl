# Сәйкестік чек-листі

Дереккөз: «Дербес деректер және оларды қорғау туралы» ҚР Заңы № 94-V (adilet.zan.kz), «Жасанды интеллект туралы» ҚР Заңы.

| Сұрақ | Жауап |
|---|---|
| Қандай ДД өңделеді | Клиент: аты, телефон нөмірі, Telegram chat_id, пошта (міндетті емес), жазылу тарихы (қызмет, уақыт, келді/келмеді). Иесі: логин. Арнайы санаттағы деректер (денсаулық т.б.) жиналмайды. |
| Негізі және мақсаты | Субъектінің келісімі (ДД заңы, 8-бап): жазылу формасындағы міндетті белгі, келісім мәтінінің нұсқасы мен уақыты сақталады. Мақсаты — жазылуды орындау және еске салу. Жарнама таратуға пайдаланылмайды. |
| Қайда сақталады | Дерекқор мен резервтік көшірмелер ҚР-дағы VPS-те (hoster.kz) — 12-баптың 2-тармағы. Telegram-ға тек уақыт пен қызмет атауы жіберіледі, аты мен телефон жіберілмейді. |
| Кімнің қолжетімділігі бар | Тек Әлібек Сапаров (әкімші). Әзірлеуші — тек қолдау кезінде, иесінің рұқсатымен, жеке тіркелгімен. |
| Сақтау мерзімі | Мақсатқа жеткенге дейін (12-бап): соңғы келуден кейін 12 ай. Кейін автоматты түрде жойылады (18-бап). Келісім қайтарылса — 15 жұмыс күні ішінде өңдеу тоқтатылады (8-бап 7-т.). |
| Журнал | Жазылуды жасау, өзгерту, жою және әкімшінің кіруі тіркеледі: кім, қашан, не (22-бап 1-т., ZHL-33). |
| Иесінің міндеттері | ДД тізбесі мен ДД саясаты құжатын Әлібек бекітеді (25-бап 2-т.): жобасы docs/security/compliance.md-де. Қорғау шаралары — STRIDE кестесінде. |
| ЖИ компоненті | MVP-да жоқ. 12-ЗЖ-да қосылса — «Жасанды интеллект туралы» Заң (2026 жылғы 18 қаңтардан күшінде) бойынша тәуекел деңгейі анықталады (ең төменгі / орташа / жоғары). Жазылу көмекшісі ең төменгі деңгейге жатуы ықтимал; пайдаланушыға ЖИ қолданылғаны хабарланады. |
| Репозиторий | Репозиторий жабық. Нақты ДД репозиторийге түспейді: тест деректері генерацияланады. Құпиялар .env-те, ол .gitignore-да. |
