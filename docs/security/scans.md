# Сканерлер нәтижесі

| Құрал | Не тексерілді | Нәтиже | Логта |
|---|---|---|---|
| gitleaks 8.21.2 (dir) | Репозиторийдің барлық файлдары | Құпия табылмады | R9: CI-да әр PR-да |
| gitleaks detect | Коммиттер тарихы (клон) | Клон арқылы тексеріледі | I3 |
| Trivy fs | Тәуелділіктердің осалдықтары | Тәуелділік файлы әлі жоқ — тексеретін нысан жоқ | I3, R18 |

Командалар (репозиторий түбірінен):

```
docker run --rm -v $(pwd):/src aquasec/trivy fs /src
docker run --rm -v $(pwd):/path zricethezav/gitleaks:latest detect -s /path -v
```
