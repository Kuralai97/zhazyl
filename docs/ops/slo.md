# SLI / SLO / SLA — «Жазыл»

Жұмыс уақыты 10:00–20:00, дс–сб (≈ 260 сағ/ай). Кезең — 30 күн. Өлшеу — Uptime Kuma және қосымша логтары.

| Сценарий | SLI | SLO | Error budget | SLA |
|---|---|---|---|---|
| Клиент онлайн жазылады | Сәтті сақталған және < 2 с жазылу сұраныстарының үлесі | 99 % | 1 % ≈ 2,6 сағ/ай | 98 % |
| Иесі күнтізбені ашады | < 1 с ашылған беттер үлесі | 95 % | 5 % баяу | 90 % |
| Клиент еске салғыш алады | Жазылудан 24 ± 1 сағ бұрын жіберілгендер үлесі | 98 % | 2 % ≈ 5 хабарлама/ай | 95 % |

SLA бұзылса: тегін жөндеу және 3 жұмыс күнінде postmortem. Айыппұл жоқ.

## Error budget ережесі
| Жұмсалуы | Әрекет |
|---|---|
| < 50 % | Жаңа функциялар кесте бойынша |
| ≥ 50 % | Тек түзетулер, себебі талданады, иесіне хабарланады |
| 100 % | Кезең соңына дейін жаңа функциялар тоқтатылады |
