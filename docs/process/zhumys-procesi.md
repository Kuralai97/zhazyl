Команда бір адам, сондықтан «тексеру» — өзін-өзі тексеру. Жазған бойда тексермеймін: басқа тапсырмаға ауысып, кейін қайтып келемін, сонда қатені «суық көзбен» көру оңай.

Курс кестесі артта қалғандықтан спринттер сағатпен өтеді (бір спринт шамамен 3 сағат). Сондықтан уақыт күнмен емес, сағат:минутпен жазылады.

## Ауысу ережелері
- Бэклог → Жұмысқа дайын: DoR орындалды.
- Жұмысқа дайын → Жұмыста: «Жұмыста» бағанында 2-ден аз карточка бар. «Жұмысқа алынды» өрісіне уақыты жазылады (мысалы 22:10).
- Жұмыста → Тексеруді күтеді: нәтиже репозиторийде. «Тексеруге берілді» өрісіне уақыты жазылады.
- Тексеруде → Дайын: DoD бойынша тексерілді. «Дайын болды» өрісіне уақыты жазылады, issue жабылады.
- Шекке жеттің бе — жаңасын алмаймын, барын аяқтаймын.

## Definition of Ready (DoR)
- Тапсырманың мақсаты түсінікті, рөлі мен пайдасы жазылған.
- Қабылдау критерийі бар (Given–When–Then немесе тексерілетін тізім).
- Тәуелділігі жоқ немесе расталған.
- Бір спринтке сыяды (шамамен 1 сағаттан аспайды).

## Definition of Done (DoD)
- Нәтиже репозиторийдің main тармағында.
- Қабылдау критерийлері тексерілді.
- Код болса: `python manage.py test` өтеді.
- gitleaks құпия таппады.
- Қажет болса README немесе docs жаңартылды.
