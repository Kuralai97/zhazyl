Команда бір адам, сондықтан тексеру — өзін-өзі тексеру. Жүктеген бойда тексермеймін: келесі тапсырманы бастап, кейін қайтып келемін.

## Тексеру чек-листі (1-спринттің ретросынан кейін қосылды)
- Тапсырма папкасындағы әр файл репозиторийде бар ма — бір-бірлеп салыстырамын.
- Файл ашылады, мазмұны дұрыс.
- Қабылдау критерийлері орындалды.

## Тақтадағы өрістер
| Өріс | Түрі |
|---|---|
| Status | 6 баған |
| Спринт | Single select |
| Жұмысқа алынды, Тексеруге берілді, Дайын болды | Text (сағат:минут) |

Date өрісінде сағат жоқ, сондықтан Text қолданылады. Уақыт карточканы жылжытқан сәтте жазылады.

## Definition of Ready (DoR)
- Мақсаты мен пайдасы жазылған.
- Қабылдау критерийі тексерілетін түрде берілген.
- Тәуелділігі жоқ немесе расталған.
- Бір спринтке сыяды.

## Definition of Done (DoD)
- Нәтиже main тармағында.
- Қабылдау критерийлері тексерілді.
- Код болса: `python manage.py test` өтеді.
- gitleaks құпия таппады.
- Құжаттама жаңартылды.

Әзірге жоқ: екінші адамның ревьюі (жобада бір адам) және стендке орналастыру (стенд жасалғанда DoD-ге қосылады).
