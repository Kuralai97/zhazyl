# 2-спринт

Кезең: 14:30–14:36.

## Спринт мақсаты
Иесі жазылуларды әкімші панелінде қосып, статусын белгілей алады.

## 1-спринттен енгізілген өзгеріс
- Өзгеріс: тексеруде тапсырма папкасындағы әр файлды репозиторийдегімен бір-бірлеп салыстырамын.
- Қалай тексеремін: «Дайын»-нан кейін түзетілген тапсырма саны 0 болуы керек (1-спринтте 1).

## Спринт бэклогы
| Тапсырма | Нәтиже |
|---|---|
| T6 ZHL-28 Жазылу | Жазылу моделі, уақыт қабаттасуы мен келісім тексерісі, тесттер |
| T7 ZHL-27 Статус | «Өтті» / «Келмей қалды» әрекеттері |
| T8 ZHL-12 Күнтізбе көрінісі | Күн бойынша сүзгі, іздеу, күн иерархиясы |

## Шолу
- Не көрсетілді: әкімші панелінде жазылу қосу, уақыт қабаттасса сақталмауы, статусты белгілеу, күн бойынша сүзгі.
- Мақсатқа жетті ме: иә, 3 тапсырманың бәрі «Дайын».

## Ретроспектива
- Метрикалар: throughput = 3, орташа cycle time = 3,0 мин, p85 = 3,7 мин, тексеру кезеңінің үлесі = 78 %.
- 1-спринтпен салыстыру: cycle time 5,2 → 3,0 мин, p85 7,6 → 3,7 мин. Тапсырмалар кішірек болды, сондықтан бұл тек өзгерістің әсері емес.
- Енгізген өзгеріс көмектесті ме: иә, «Дайын»-нан кейін түзетілген тапсырма 1 → 0.
- Тар жер: әлі де тексеру кезеңі.
- Келесі спринтке бір өзгеріс: «Тексеруді күтеді» шегін 2-ден 1-ге түсіремін. Иесі: Құралай. Өлшемі: тексеру кезеңінің үлесі 50 %-дан төмен.
