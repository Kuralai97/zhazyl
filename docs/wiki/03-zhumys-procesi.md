# Жұмыс процесі

## Тақта статустары

| Статус | Кіру шарты | Шығу шарты |
|---|---|---|
| Backlog | Тапсырма жазылды | Қабылдау критерийлері мен өлшемі қойылды |
| Ready | Критерийлер жазылған, өлшемі S немесе M | Жұмыс басталды |
| In progress | WIP ≤ 2 | Нәтиже дайын, тармақ push жасалды |
| Review | WIP ≤ 2 | 24 сағаттан кейін чек-лист бойынша тексерілді |
| Blocked | Сыртқы бірдеңені күтіп тұр (себебі пікірде жазылады) | Кедергі алынды |
| Done | Чек-лист өтті, тармақ main-ге біріктірілді | — |

## Тақтаның өрістері

- **Size:** S (≤ 2 сағ), M (≤ 6 сағ), L (6 сағаттан көп — алдымен бөлшектенеді).
- **Owner:** тапсырманы орындаушы.
- **Iteration:** итерацияның нөмірі (2 апта).
- **Risk ID:** тапсырма байланысты тәуекел (R-1, R-2…).

## Атау келісімдері

- **Тапсырма префиксі:** `ZHL`. Мысалы: ZHL-12.
- **Тармақ:** `<түрі>/ZHL-<нөмір>-<қысқа-атауы>`. Мысалы: `feat/ZHL-10-onlain-zhazylu`, `docs/ZHL-2-adr-001`.
- **Коммит:** `feat:`, `fix:`, `docs:`, `chore:` префикстерімен. Мысалы: `docs: ADR-001 жеткізу моделі қосылды`.
- **Ереже:** бір тармақ — бір тапсырма. Тармақ 3 күннен ұзақ өмір сүрмейді.

## Ырғақ

- Әр жұма — жоспарды жаңарту (30 мин).
- 2 аптада бір рет — итерацияны жоспарлау және қорытындылау, тапсырыс берушіге демо (20 мин).
