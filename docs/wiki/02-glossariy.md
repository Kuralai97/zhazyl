# Глоссарий

| Термин | Мағынасы |
|---|---|
| Жазылу | Клиенттің белгілі бір қызметке белгілі бір күн мен уақытқа брондауы |
| Қызмет | Бизнес ұсынатын жұмыс түрі; ұзақтығы мен бағасы бар (мысалы, шаш қию — 60 мин) |
| Слот | Жазылуға болатын бос уақыт аралығы |
| Жұмыс кестесі | Бизнестің жұмыс күндері мен сағаттары; слоттар осыдан есептеледі |
| Растау | Жазылу сақталғаны туралы клиентке жіберілетін хабарлама |
| Еске салғыш | Жазылудан 1 күн бұрын клиентке жіберілетін хабарлама |
| Келмей қалу (no-show) | Клиенттің ескертусіз жазылуға келмеуі |
| Жазылу статусы | Жаңа → Расталған → Өтті / Бас тартылды / Келмей қалды |
| Инкремент | Тапсырыс берушіге көрсетуге болатын, жұмыс істейтін жүйе бөлігі |
| WIP | Бір мезгілде жұмыста тұрған тапсырмалар саны |
| ADR | Шешім жазбасы (Architecture Decision Record) |
| DoR / DoD | Жұмысқа алуға дайындық анықтамасы / аяқталғандық анықтамасы |
