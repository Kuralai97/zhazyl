# ADR-002. Технологиялық стек

- Статус: қабылданды
- Шешім қабылдаған: Мырзатаева Құралай (PM)

## Контекст
MVP-ді бір адам 60 сағатта жасауы керек (5-ЗЖ). Иесіне қызметтер, кесте және күнтізбе беттері керек. Деректер ҚР-дағы VPS-те сақталады (7-ЗЖ, 12-бап). Ақшалай шығын — 0 ₸.

## Шешім драйверлері
1. Иесінің беттерін жеке жазбай, дайын әкімші панелін қолдану (5-ЗЖ-да −9 сағ).
2. Бір адам меңгере алатын қарапайымдылық.
3. Лицензия ақысы жоқ, ашық код.

## Қаралған нұсқалар
| Нұсқа | Артықшылығы | Кемшілігі |
|---|---|---|
| Django + PostgreSQL | Дайын әкімші панелі, ORM, тест құралдары бірге келеді | Python білу керек |
| Node.js (Express) + React | Интерфейсті икемді жасауға болады | Әкімші панелін нөлден жазу керек — +9 сағ |
| WordPress + жазылу плагині | Тез іске қосылады | Плагиндер ақылы немесе шектеулі, логиканы өзгерту қиын |

## Шешім
Django 5.2 (LTS) + PostgreSQL. Әзірлеуде SQLite. Иесінің беттері — Django admin.

## Салдары
- Иесіне арналған интерфейс қарапайым болады, әдемі дизайн 2-нұсқаға қалады.
- R3 тәуекелі (7-ЗЖ) жабылады: әкімші панелі қызмет пен кестені енгізуге жетеді. Күнтізбе көрінісін 2-спринтте тексеремін.
- requirements.txt пайда болды — Trivy енді тәуелділіктерді тексере алады (I3 проблемасы).
- Қайта қарау: егер күнтізбе көрінісі әкімші панелінде 4 сағатта жасалмаса.
