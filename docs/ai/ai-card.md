# AI функциясының карточкасы: хабарламаларды жіктеу

| Бөлім | Мазмұны |
|---|---|
| Функция | Барбершопқа WhatsApp-қа келген хабарламаны бес топтың біріне жатқызу: жазылу, ауыстыру, бас тарту, сұрақ, басқа. Әкімші панелінде хабарламаның жанында топ белгісі тұрады |
| Кімге | Иесі (Әлібек Сапаров). Клиенттерге көрінбейді |
| Бизнес-метрика | Бас тарту мен ауыстыру хабарламаларына жауап беру уақыты: босаған уақытты басқа клиентке тезірек беру. Қазір иесі хабарламаларды клиент қабылдау арасында ретімен оқиды |
| Модель сапасының метрикасы | Macro F1 және әр топтың F1-і (топтар тең емес: «ауыстыру» 4, «жазылу» 10 мысал) |
| Қабылдау шарты | Macro F1 ≥ 0,85; әр топтың F1-і ≥ 0,80; AI-сыз ережеден әр топ бойынша жақсы; «бас тарту» тобында қате 0 |
| AI-сыз базалық шешім | 6 топқа бөлінген 30-ға жуық кілт сөз ережесі (scripts/ai_eval.py, RULES) |
| Не істемейді | Клиентке жауап жазбайды; жазылуды өзі жасамайды, ауыстырмайды, өшірмейді; хабарламаны жасырмайды. Тек топ белгісін ұсынады, шешімді иесі қабылдайды |
| Деректер | 36 мысалдан тұратын eval жиынтығы (evals/dataset.jsonl); эталонды екі адам тәуелсіз белгіледі, каппа 0,93 |
