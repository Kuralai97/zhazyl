# Жазыл

Шағын қызмет көрсету бизнесінің клиенттері қызмет пен бос уақытты өздері таңдап, онлайн жазылатын, ал иесі барлық жазылуды бір күнтізбеден көретін веб-жүйе.

Бұл — «IT-жобаларды басқару» курсының семестрлік жобасы (ЕҰУ, 2026 күз). Орындаушы — Мырзатаева Құралай, АЖ45 тобы.

## Қайда не жатыр

## Репозиторий құрылымы

```
docs/
  adr/            шешімдер (2, 12-ЗЖ)
  requirements/   стейкхолдерлер, story map, ФЕТ (4-ЗЖ)
  plan/           WBS, релиздер, тәуелділіктер, RACI, capacity (5-ЗЖ)
  security/       RAID-лог, қауіп моделі, сәйкестік (7-ЗЖ)
  qa/             тест жоспары, UAT, postmortem (11-ЗЖ)
  ops/            runbook, релиз жоспары, кері қайтару (10, 11-ЗЖ)
  portfolio/      қорытынды жинақ (15-ЗЖ)
  wiki/           вики беттері
notebooks/        есептеулер (6-ЗЖ)
evals/            ЖИ функциясын бағалау жинағы (12-ЗЖ)
scripts/          автоматтандыру (10, 13, 14-ЗЖ)
src/  tests/      жүйе коды және тесттер
.github/          тапсырма шаблондары және CI пайплайны (10-ЗЖ)
```

> Ескерту: репозиторий жабық (private). GitHub-тың тегін тарифінде жабық репозиторийде Wiki қосылмайды, сондықтан вики беттері `docs/wiki` каталогында сақталады.
